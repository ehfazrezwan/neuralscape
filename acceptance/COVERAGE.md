# Nodes with no green acceptance scenario

**None of the nodes below is green.** Each is either not covered by a scenario or only partly covered; the status says why (`gap`: a scenario is possible and not written or needs a harness change; `blocked`: waits on another PR, an identity provider or an operator input; `dead-code`: no live path reaches it; `not-started`: nothing exists to run; `partial`: some of it is proven). This file lists only what is known to be uncovered or partly covered; PRs it cites are checked by hand when the file is refreshed.
